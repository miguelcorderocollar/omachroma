# Changelog

## Unreleased

- Rename Omachroma to Omatinta (Oma + Spanish tinta/tint). Keep `omachroma`
  and `omapaper` data directories, wallpaper names and launchers usable as
  legacy fallbacks.

## 0.5.0 · release candidate

- Simplify the workspace, align action sizes and use compact palette swatches.
- Add organized Settings pages with Back navigation and a keyboard guide.
- Add an explicit upscaling switch and hide inactive upscale controls.
- Move model configuration into a focus-trapped modal dialog.
- Remember native image/export picker folders and block workspace shortcuts
  while dialogs, Settings or History own focus.
- Set the pixel-cut landscape O to the Tokyo Night palette and remove the swatches.
- Capture real saved-image examples and preserve reusable demo-generation code.

## 0.4.0 · release candidate

- Rename OmaPaper to Omachroma. Existing data and history paths remain usable.
- Add cached fal/OpenRouter price refresh and known-model availability checks.
- Add user editing/upscaler models, preferred defaults, hiding and manual rates.
- Use model-specific dimensions for estimates and show remaining batch totals
  only when supported by the available rates.
- Add saved-key removal, configuration/cache recovery and local dependency checks.
- Strip upload metadata and refuse credentialed HTTP redirects.
- Prepare standalone tests, install/removal instructions and preview assets.
- Document the current automatic theme saving and unchanged desktop wallpaper.

## 0.3.0 · private development

Theme-matched editing, dedicated upscalers, multi-source/multi-theme batches,
per-theme references, retained previews, history, export and reported costs.
