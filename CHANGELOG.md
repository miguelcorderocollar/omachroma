# Changelog

- Rename OmaPaper to Omachroma. Existing data and history paths remain usable.
- Add cached fal/OpenRouter price refresh and known-model availability checks.
- Add user editing/upscaler models, preferred defaults, hiding and manual rates.
- Use model-specific dimensions for estimates and show remaining batch totals

- Prepare standalone tests, install/removal instructions and preview assets.
- Document the current automatic theme saving and unchanged desktop wallpaper.
